# The reading surface is art-first and adaptive

2026-10-08. The Historia screen opens with the Hero — the artwork full-bleed, the Story scrolling up beneath it — and the app adapts to light and dark, with accent color drawn from each artwork's palette in both (Obra del día's rule, made general). Built on Expo first-party modules only — expo-image, reanimated for the parallax collapse, expo-glass-effect as the iOS-26 collapsing header (plain-View fallback elsewhere), expo-linear-gradient — and no UI kit (Tamagui, paper, gluestack, @expo/ui wholesale): kits ship their own theme system, and the product's signature is a frame that recolors per artwork. Rights-blocked works keep the art-first shape — the Hero falls back to the artwork's palette gradient (ADR-0003; las-dos-fridas is the permanent specimen). Dark mode is app-only: the public /obra pages stay as-is (ADR-0011). The Catálogo follows — the Descubre wall: one full-bleed scroll of near-screen-height cards, each the same palette-gradient-fallback model, opened by the Apertura (GLOSSARY; a random published work, re-picked every cold start) — so the app reads as a wall of paintings from screen one (2026-10-20 amendment: built as full-bleed cards; the original "thumbnails" wording is superseded). Deferred: `Link.AppleZoom` catalog→obra transition (alpha, iOS 18+ only, documented ~1s open/dismiss latency); revisit when stable.
