# Recognition grades; never a silent wrong answer

2026-09-29. When the scanner ships (Phase 3, ADR-0012), recognition returns graded confidence: high → Story card; medium → confirm card ("¿Es *El grito* de Munch?") whose tap doubles as accuracy telemetry; low → smart miss. The smart miss names what Vision identified but the Catalog lacks, plus Avísame — an anonymous Expo push token and a content request, honored on publish-flip; a denied notification permission still counts the request ("actívalas y te avisamos"). Demand collection is live from v1 via non-scanner sources — requested_via: channel | artist_page | web_form | search_miss | story_page; scanner_miss joins at Phase 3.

Rejected: Shazam-coverage ambition (a 99.9% miss rate at launch) and Wikidata fallback text on a miss — machine prose kills the *destapar* promise on first contact.
