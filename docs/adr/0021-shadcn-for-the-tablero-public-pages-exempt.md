# The Tablero is built on shadcn/ui; the public pages are not

2026-10-10. The tablero (Catálogo list + Story editor, apps/dashboard) moves to shadcn/ui — vendored components over Base UI primitives, stone base, tokens in globals.css — replacing hand-rolled `styles.ts` and the badge soup; shadcn becomes the single restyling point `styles.ts` aspired to be. Considered and rejected: Flowbite (the UI-standards default, but its CDN-era styling fights Tailwind v4's CSS-first config) and staying hand-rolled (every new widget re-invents focus states, dark mode, and variants). Consequences: server-action forms keep native `<select>` (`native-select.tsx`) because shadcn's Select is a JS popup that would silently drop its value on submit — do not "fix" this; dark mode stays `prefers-color-scheme` (no `.dark` class, no next-themes), so future shadcn CLI runs that rewrite globals.css need the media variant re-applied. The public `/obra` pages stay exempt (ADR-0011, ADR-0020): one app, two surfaces — admin-styled where we work, art-first where the audience reads.
