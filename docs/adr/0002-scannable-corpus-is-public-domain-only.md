# Scannable corpus is public-domain only

2026-09-29. Faithful photo reproductions of public-domain 2D works are treated as non-copyrightable (the Bridgeman v. Corel position; Commons operates on this at scale and hosts high-res Meninas, Goya, El Greco). Commons is the image source for the Spanish canon; the Met API is the metadata backbone, not the hero list.
