# Estilos replace Movements; obras carry a style

2026-11-26 (Patrick, grilling session). The taxonomy glossary-termed Movement renames to **Estilo** — «Estilos» to users, style in code — and goes artist-many / obra-one: `movements` → `styles`, `artist_movements` → `artist_styles`, `film_connections.movement_id` → `style_id`, and `artworks` gains a nullable `style_id` (null = unclassified). Two reasons. On Descubre the chips users expect are art styles (Impresionismo, Realismo, Arte abstracto) — and "movement", like "genre", names the wrong thing in art history (genre = bodegón, retrato, paisaje), so the filter had to speak the user's words, not the textbook's. And an artist's spans-of-career styles are not each obra's classification (Picasso's Neoclassical years sit beside his Cubist ones): a per-obra single style — the dominant one, or nothing until the editor sets it — is the honest unit for a wall filter, set by hand in the Tablero like every editorial claim.

Rejected: artist-derived obra classification (the artist's style set filters the wall by inheritance, showing obras under styles the individual work doesn't claim); an `artwork_styles` join table (many-per-obra multiplies editor minutes per obra for v1 — ADR-0006 — and the filter UI is single-select; a later join can replace the FK at migration cost only); renaming only the user-facing strings while keeping movement schema names (the schema header's canon rule — every table maps to a glossary term — would drift exactly where this ADR is enforcing).

Descubre gains the Estilos strip: an inline horizontal carousel after the third wall card (scrolled with the wall, never sticky) — each chip shows the style's representative obra (ADR-0023 derivation: the style's first published obra with a display image, by `title_es`; palette-gradient monogram when none) with the style name (Es) beneath, and single-select routes to a browse list of that style's published obras in title order — a derived view, not an editorial surface, so pure-taxonomy-at-v1 holds. Dev-time only, a «Sin clasificar» chip exposes unclassified published obras, retiring once every published obra carries a style — a placeholder, not a permanent type (unlike Story-only lesson, ADR-0003).

2026-11-26, same-day addendum (Patrick): the taxonomy stops being name-only. `styles` gains a nullable `description` — seed text, Patrick's 13-entry vocabulary (four new styles join the nine: Neoclasicismo, Pop Art, Minimalismo, Arte conceptual; each entry carries a short definition and a representatives line, migration `20261126130000`) — and the Tablero's Estilo dropdown groups its options under three presentation-level headings («Realismo y representación de la forma», «Luz, color y ruptura moderna», «Abstracción y arte contemporáneo»): grouping is a slug→group constant in the picker, never a column on styles (that is the genre field this ADR keeps off the table), and a style no group claims falls into an «Otros» group so future seed or import entries never vanish. The vocabulary is used at the choosing moment only: a native select renders option names alone, so a small client island echoes the chosen style's description beneath. The browse strip and /estilo screen stay derived views.
